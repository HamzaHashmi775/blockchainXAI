# Manuscript (Journal of King Saud University – Computer and Information Sciences)

Target journal: JKSUCI, Springer Nature (link.springer.com/journal/44443). Double-anonymous
review: submit the blinded manuscript and the title page as separate files.

| File | Content |
|---|---|
| `main.tex` | blinded manuscript (no author names, no identifying links) |
| `title_page.tex` | title page with author details and declarations; **fields in [brackets] must be completed by the author** |
| `references.bib` | bibliography; every entry fetched from Crossref, DataCite or arXiv by its identifier (`refs.txt`), except Holm (1979), which has no DOI, and the SCMS data citation (from `data/metadata/datasets.json`) |
| `tables/tab_*.tex` | LaTeX tables, generated by `make_paper_tables.py` from `results/summaries/` |
| `check_manuscript.py` | word counts, citations vs bibliography, files used, identifying strings |

Figures are the PDFs in `../figures/` (generated by `statistics/make_figures.py`).

## Compiling (Overleaf)

No LaTeX installation is needed locally.

1. In Overleaf, open the official **Springer Nature LaTeX Template** (v3.1) from the template
   gallery; it provides `sn-jnl.cls` and `sn-basic.bst`.
2. Upload `main.tex`, `title_page.tex`, `references.bib` and the folder `tables/`.
3. Create a folder `figures/` and upload `fig1`–`fig8` (`*.pdf`) from `../figures/`.
4. Set `main.tex` as the main document and compile (pdfLaTeX + BibTeX).

## Regenerating

```bash
python paper/make_paper_tables.py   # tables from results/summaries/
python paper/check_manuscript.py    # checks before submission
```

`python reproduce.py` regenerates these tables together with everything else.

## Before submission (author)

- Complete the bracketed fields in `title_page.tex` (affiliation, e-mail, ORCID, funding,
  competing interests, author contributions) and check the declarations in `main.tex`.
- Read and approve the generative-AI statement (Methods, §3.6, and title page). The journal
  requires generative-AI use to be documented in the Methods.
- Prepare an anonymised copy of the repository for reviewers (the GitHub repository name
  identifies the author).
- Sign the journal's author agreement.
